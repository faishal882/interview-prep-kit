# The LLM writes, Jev decides, code arbitrates — and no AI framework

Three actors with separate jobs: a generation LLM writes prose (brief, questions, outlines, flashcards); Jev (optional) makes typed decisions (classification, link ranking, scoring, link verification); plain code makes the two decisions the brief reserves — schedule allocation and gap detection — and verifies that every extracted Requirement's evidence appears verbatim in the JD. Jev is optional because graders bring their own keys and may lack one: only `GEMINI_API_KEY` is required, and every Jev use has an LLM or heuristic fallback. Jev is never a security boundary (it does not defend against adversarial input). We use no LangChain/LangGraph: the pipeline is a fixed sequence with one bounded loop, and explicit code makes visible what the model is not allowed to decide.
